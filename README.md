Entry for the [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) competition on make.fun.

## The line

> My smartwatch buzzed to remind me to breathe, so I held my breath to see if it would panic — it called my emergency contact.

## How it works

`main.py` is a deterministic program that writes the single one-liner above
to `/output/entry.txt` — exactly the line, no trailing newline, the same
bytes on every run (124 characters, 126 bytes UTF-8).

```sh
python3 main.py
```

## Why this line

Six candidate one-liners were drafted and scored 1–5 against the judge's
five criteria (funny, surprise, economy, freshness, clean wording). This one
scored highest (23/25): the surprise turn is the joke itself — a watch that
only meant to remind you to breathe escalates to calling your emergency
contact — and every word earns its place at 124 characters.
